# Cloud PNGs

Hand-painted clouds used by the `Cloud` component in `src/App.jsx`.

| file              | description                                   | used for                          |
|-------------------|-----------------------------------------------|-----------------------------------|
| `cloud-wisp.png`  | pale white, thin streak rising left-to-right  | upper-sky wisps in the hero       |
| `cloud-big.png`   | blue gradient, long low band with a peak      | hero front band, schedule V arms  |
| `cloud.png`       | blue gradient, wide rounded bank              | hero back bank, front band, schedule V |
| `cloud-side.png`  | blue gradient, big puff with a tail           | spare                             |
| `cloud-white.png` | pale white, wide soft puff                    | schedule trough                   |
